This folder contains all the scripts and some of the data used in my report.

To train a model as described in the report, run model_trainer.py with the relevant arguments.

To evaluate models and reproduce some of the graphs in the report, run relevant cells in model_evaluator.ipynb.

The packages you will need include:
    ipywidgets, numpy, pandas, scipy, pytorch, and torchdiffeq
For a full list of packages that I had dowloaded while experimenting, reference conda-list.txt.
